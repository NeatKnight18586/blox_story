# BRAND: what every episode promises

**Promise:** "Every rule has a loophole. Can you find it first?"

- **Hero.** ONE recurring first-person hero (`cast/hero.json`, slot HERO) in every episode, a new world each time. Supporting
  cast = troupe slots (`cast/troupe.json`: LEAD, SECOND, LITTLE, RIVAL, ELDER), re-costumed per episode.
- **Voice.** One ElevenLabs narrator voice, first person (D1, `V4.md`). Opener: "In this world, …". Ending: the twisted rule line.
- **Look.** Lit, detailed worlds + blocky characters; satin plastic bodies. Own designs only; never the Roblox logo or wordmark,
  never imply official. No labels on people or objects (SEASON_1 §2c).
- **Title template:** the rule + one capitalised emotional word + one emoji + `#shorts #roblox`.
- **Pinned comment:** the comment question + "Did you find the loophole before me?"
