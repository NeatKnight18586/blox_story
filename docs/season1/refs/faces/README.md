# Face style references (owner, for STYLE only)

Never shipped, never rendered, never traced, never pixel-sampled, never named after. They show the
look the owner wants: thick ink lines, big white eyes with highlights, blush marks, sweat drops, tears,
huge mouths, lashes on modern girl faces. Our faces are redrawn from scratch in that style (Faces v3).

- ref1: the target expressiveness (most important).
- ref2: modern girl faces (lashes, glossy eyes, blush, kiss/wink) and cartoon reactions.
- ref3: simple classic faces (blocky, disappointed, happy, crying, monster teeth).
- ref4: red-marked faces are excluded by the owner; use only unmarked ones (and never the meme
  "trolling" face).
