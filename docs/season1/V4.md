DECISIONS (owner)
Format v5: episodes 75-90 s (hard max 90 s); 24 fps output; voice untouched (D3).
D1 narration: first person for the hero ("I…"). The owner writes every script; Claude Code never writes or edits narration.
D2 floating game numbers: no. Numbers only on in-world signs and phone screens.
D3 voice: the owner's voice file is used exactly as delivered. Never trim, stretch, or edit it.
D4 sets: a reusable library of locations; each episode re-dresses them.

V4 SESSION RULES (token and time budget)

- Never write or change stories/*/script.txt or voice files. Episodes are built only from the owner's script, voice and beats prompt.

- Not used in v4: planar or screen-space reflections, mirror water, cascaded shadows, real-time AO passes, bloom passes, volumetric fog, GPU machines.
- Plan in <= 10 lines, then work; no step-by-step narration.
- Run the "Nobody" byte-identity check only when engine/episode.js, scripts/v2/render.js or assemble.py changed.
- Final report <= 25 lines in this order: Done (bullets) / Checks (number vs target, PASS/FAIL) / Three weakest things per sheet / Decisions for the owner / Commit hash.
